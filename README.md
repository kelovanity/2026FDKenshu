# SGS Future Division Kenshu 2026 RSVP tracker

Static Vercel site. It reads the public Google Sheet every minute and uses:

- column B: latest RSVPs
- column C: target RSVPs
- column D: percentage towards goal

Upload the contents of this folder to the root of the `2026FDKenshu` GitHub repository, then connect that repository to the `2026fdkenshu` Vercel project.
